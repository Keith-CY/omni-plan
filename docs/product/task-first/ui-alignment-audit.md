# 任务优先流程：桌面端视觉复查

复查日期：2026-09-18
范围：快捷记录、收件箱、待办详情、今天时间线、拆分项目弹窗、项目首页。

## 结论

核心流程已统一到同一套桌面端密度：主内容最大宽度一致，一级标题收敛到 32px，表单行按两列/四列网格对齐，时间线短任务使用紧凑时间标签，项目摘要卡和高级计划入口恢复统一边框与等宽布局。

## 已修正

- 收件箱由 1120px 独立宽度改为与今天、项目一致的 1440px 内容上限。
- 主标题最大字号由约 38px 收敛到 32px；快捷记录输入和切换控件同步缩小。
- 待办详情中标题/备注、日期、工作量/标签、重点标记重新对齐；分钟后缀不再与数字输入器重叠。
- 今天视图的任务列、时间轴和展开编辑器使用同一列起点；一小时任务只显示开始时间，完整区间保留在可访问说明中。
- 项目摘要卡改为等宽两列；“高级计划”改为完整、有边界的可点击行。
- 侧边栏品牌保持单行；审查日期改为中文“截至”。

## 六步流程健康度

1. 快捷记录：健康。面板紧凑，默认只要求一句话。
2. 补日期与工作量：健康。字段分组清楚，输入后缀和操作区对齐。
3. 安排今天：健康。任务、时间轴和编辑器共享网格，短时间块不截字。
4. 打开完整详情：健康。渐进展开保持完整能力，但不影响首次记录。
5. 拆成项目：健康。弹窗层级明确，两种方法选项尺寸一致。
6. 项目首页：健康。默认先显示目标、下一步和任务，高级能力继续折叠。
